## Что уже есть

- `bookshelf_app`: `Author`, `Genre`, `Book` (+`added_by`), `Review` (оценка 1–5, создаётся только
  в админке / `gen_data`), CRUD книг на CBV, примесь `Breadcrumbs`, общий каталог `/books/`.
- `user_app`: `CustomUser` (вход по email), регистрация/вход/профиль, публичная страница читателя.
- Инфраструктура: Postgres, Celery + Redis (`log_new_book_task`), тесты (порог покрытия 95%),
  три CI, docker compose.
- Главная страница (`index.html`) — заглушка с одним заголовком.

## Чего не хватает главного

Нет самой сущности дневника: нельзя отметить, что книга прочитана, читается или запланирована.
Сейчас «моё» — это только книги, которые я добавил в общий каталог.

## Этапы

### 1. Модель дневника
- Новая модель `ReadingEntry` в `bookshelf_app/models.py`: FK `reader`, FK `book`,
  `status` (`planned` / `reading` / `read`, `TextChoices`), `started_at`, `finished_at`,
  `created_at`, `updated_at`; `unique_together = (reader, book)`, `related_name='entries'`.
- Отзыв и оценка переезжают в неё же (`rating`, `text` — необязательные, заполняются после
  прочтения), модель `Review` удаляется: одна запись дневника = одна книга одного читателя.
- Миграции удалить и сгенерировать заново (`0001_initial`), БД пересоздать.
- Регистрация в админке, наполнение в `gen_data`.

### 2. Главная страница = дневник
- `IndexView`: для гостя — приветствие и кнопки входа/регистрации; для читателя — три колонки
  «Читаю сейчас», «Прочитано», «Хочу прочитать» из его `ReadingEntry`.
- Счётчики по статусам, ссылки на карточку книги.
- Отдельная страница `/diary/` не нужна — дневник живёт на `/`.

### 3. Действия над книгой
- На странице книги и в списке каталога — кнопки смены статуса
  («Хочу прочитать» → «Читаю» → «Прочитано») для авторизованного пользователя.
- Вьюха смены статуса (POST, `LoginRequiredMixin`), проставление `started_at` / `finished_at`.
- Удаление книги из дневника.

### 4. Отзывы через сайт
- `EntryReviewView` (UpdateView по записи дневника): оценка и текст со страницы книги.
- Предлагается сразу после перевода книги в «Прочитано».
- Средняя оценка и число прочтений книги в каталоге (`Avg`/`Count` в `get_queryset`),
  чужие отзывы — на странице книги.

### 5. Каталог как второстепенная вкладка
- В списке книг — фильтры (жанр, автор, поиск по названию) и пагинация.
- Пометка «уже в моём дневнике» у книг со статусом.
- Меню: «Мой дневник» (главная) первым пунктом, «Все книги» — вторым.
